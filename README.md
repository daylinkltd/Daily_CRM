# Daylink CRM

Unified Omni-channel CRM — Shared inbox, contacts, sales pipelines, broadcasts, and no-code automations. Built for modern high-performance teams.

## Key Features

- **Shared Inbox**: Multi-channel shared inbox for WhatsApp, Instagram, Messenger, and Email with per-conversation owner assignment.
- **Contacts & Fields**: Manage contacts, tag lists, and customize variables or custom fields easily.
- **Sales Pipelines**: Visual Kanban deal pipeline linked to customer conversations.
- **Broadcasts**: Send Meta-approved template broadcasts with placeholders, schedule, and read tracking.
- **No-Code Automations**: Visual flow builder for inbound auto-replies, keyword triggers, delays, and integrations.
- **Real-Time Dashboards**: Response speed analytics, message volumes, pipeline performance, and activity feeds.

## Tech Stack

- **Frontend/Backend**: Next.js 16, React 19, TypeScript, Vanilla CSS.
- **Database & Auth**: Supabase (Postgres + Auth + Storage + RLS).
- **Payment Gateway**: Razorpay standard checkout integration.
